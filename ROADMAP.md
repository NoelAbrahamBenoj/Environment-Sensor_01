Long-Term Feature Ideas
- Integrate with an ML model(1) that predicts sleep quality with changes in environment
- Implement a flutter app to make it mobile accessible
- Introduce a DBMS to collect and store data
- Introduce an ML model(2) that can accurately remap sensor data if 
  sensor thresholds or sensitivities differ in different hardware models.
- Host a website with access to training data and ML model(2) so as to scale to anyone who has access to hardware components and instructions to assemble.
-Introduce an ML model(1) type in the website so that anyone can train untrained model with their own data.
